Learning Dual-task Descriptors using Unidirectional Feature Fusion for RGB based Category-level Object Pose EstimationLearning Dual-task Descriptors using Unidirectional Feature Fusion for RGB based Category-level Object Pose Estimation

Wendong Guo, Junyi Wang, Yanwei Zheng*, Xiao Zhang, Xingyu Zhang, Dongxiao Yu

Neural NetworksNeural NetworksCCF BCCF B

面向单张 RGB 的类别级6D位姿与尺寸估计，以双任务描述子、单向几何融合和候选置信度聚合增强预测；REAL275 NIoU50为51.4，RTX 3090上达24 FPS。For RGB-only category-level 6D pose and size estimation, dual-task descriptors, one-way geometric fusion, and confidence-weighted aggregation strengthen predictions; REAL275 NIoU50 is 51.4, with 24 FPS on an RTX 3090.

任务说明Task

类别级位姿估计需要从已知类别中识别未见过的物体实例，并预测其相对相机的三维位置、旋转和尺寸。只输入 RGB 图像时，模型还需克服纹理与形状差异以及尺度歧义。Category-level pose estimation predicts camera-relative 3D translation, rotation, and size for unseen instances from known categories. RGB-only input makes the task difficult because of texture and shape variation and scale ambiguity.

DDPoseNet 将问题转化为图像像素与三维模型点的描述子对应，同时完成目标分割与位姿求解，避免把外部检测器作为必需前置步骤。DDPoseNet formulates the task as descriptor correspondences between image pixels and 3D model points. Segmentation and pose estimation are learned together without requiring an external detector as a prerequisite.

主要贡献Main Contributions

  • 学习同时支持像素分割和 2D–3D 对应的双任务描述子，在同一框架内求解位姿与真实尺度。Dual-task descriptors support both pixel segmentation and 2D–3D correspondence, enabling pose and metric-scale recovery in one framework.
  • 采用单向特征融合，让三维几何信息增强图像描述子，同时保持模型分支可独立预计算。One-way feature fusion enriches image descriptors with 3D geometry while keeping the model branch independently precomputable.
  • 预测不同候选模型的位姿置信度，再加权聚合多个候选，减小模型选择带来的不确定性。Predicted confidence scores weight and aggregate poses from different model candidates to reduce model-selection uncertainty.

方法架构Method Architecture

图像分支采用 Swin Transformer，点云分支采用 Point Transformer V3，辅以冻结 DINOv2 的几何特征。单向融合模块用几何分支指导图像特征，网络同时学习描述子相似性、距离关系与分割目标。A Swin Transformer encodes images and Point Transformer V3 encodes model points, with frozen DINOv2 features providing auxiliary geometric cues. One-way fusion guides the image branch with geometry, while training combines descriptor similarity, distance relations, and segmentation objectives.

推理时先进行像素和模型描述子匹配，建立 2D–3D 对应并通过 PnP 生成候选位姿。对于同类多个实例，根据对应点的位姿一致性区分目标，最后以置信度加权融合候选。At inference, pixel and model descriptors establish 2D–3D correspondences and PnP produces pose hypotheses. Pose consistency among correspondences helps distinguish multiple same-category instances, after which confidence-weighted aggregation gives the final pose.

实验结果Experiments and Results

类别级实验在 REAL275 与 CAMERA25 上进行。使用三维模型的 REAL275 结果为 NIoU50 51.4、NIoU75 27.3、IoU50 22.4；不用真值三维模型、以训练样本重建模型的设置仍取得 NIoU50 51.1。Category-level evaluation uses REAL275 and CAMERA25. With 3D models on REAL275, NIoU50 is 51.4, NIoU75 27.3, and IoU50 22.4. Replacing ground-truth models with reconstructions from training samples still obtains 51.1 NIoU50.

实例级 YCB-Video 测试达到 ADD(-S) 86.1、ADD-S AUC 93.3 和 ADD(-S) AUC 89.4。单向融合、位姿置信度和双任务描述子均通过消融验证；在 RTX 3090 上，REAL275/CAMERA25 推理速度为 24 FPS。On the instance-level YCB-Video benchmark, ADD(-S) is 86.1, ADD-S AUC 93.3, and ADD(-S) AUC 89.4. Ablations evaluate one-way fusion, pose confidence, and dual-task descriptors. Inference on REAL275/CAMERA25 runs at 24 FPS on an RTX 3090.
