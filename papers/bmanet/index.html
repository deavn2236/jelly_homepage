Boundary-aware Multimodal Alignment Network for Video Temporal GroundingBoundary-aware Multimodal Alignment Network for Video Temporal Grounding

Wendong Guo, Junyi Wang, Yanwei Zheng*, Xiao Zhang, Xingyu Zhang, Dongxiao Yu

ACM Transactions on Multimedia Computing, Communications, and ApplicationsACM Transactions on Multimedia Computing, Communications, and ApplicationsCCF BCCF B

面向自然语言视频时刻检索与高光检测，以查询增强、门控去噪和自适应时序金字塔改善跨模态对齐与片段边界；QVHighlights 验证集全监督平均 mAP 为54.3。For language-based video temporal grounding and highlight detection, query enhancement, gated denoising, and an adaptive temporal pyramid improve alignment and boundaries; fully supervised average mAP is 54.3 on QVHighlights validation.

任务说明Task

视频时刻检索根据自然语言查询，在未剪辑视频中找出对应片段的起止时间；高光检测为各帧预测与查询相关的显著度。两者都要求在长视频中建立准确的图文关联。Moment retrieval localizes the start and end of the segment corresponding to a natural-language query in an untrimmed video. Highlight detection predicts query-related frame saliency. Both require accurate alignment between a short query and a long visual sequence.

密集视觉内容与稀疏文本之间的噪声容易造成边界过长、截断或相邻事件合并。不同事件持续时间差异明显，也要求时序表示适应多个尺度。Noisy alignment between dense visual content and sparse text can overextend or truncate boundaries and merge neighboring events. Variable event durations also require temporal representations at multiple scales.

主要贡献Main Contributions

  • 设计查询增强与噪声抑制模块 QENS，用可学习 token 扩充查询语义，并以门控机制过滤与查询无关的视觉响应。QENS enriches query semantics with learnable tokens and gates visual responses unrelated to the query.
  • 设计自适应时空金字塔 ASP，结合多分辨率表示与选择性通道更新，刻画长短事件及其边界。ASP combines multi-resolution representations and selective channel updates to model events of different durations and their boundaries.
  • 统一优化时刻检索和高光检测，同时输出片段边界、置信度和帧级显著度。Joint optimization supports moment retrieval and highlight detection, producing segment boundaries, confidence scores, and frame-level saliency.

方法架构Method Architecture

首先提取并对齐视频和查询特征。QENS 通过自适应注意力和可学习 token 增强文本，再以门控层动态抑制背景响应，生成更清晰的查询相关视觉表示。Video and query features are first extracted and aligned. QENS enhances textual semantics with adaptive attention and learnable tokens, then dynamically gates background responses to produce cleaner query-conditioned visual features.

ASP 逐层建立不同时间分辨率的表示，在细粒度与粗粒度分支间结合选择性特征更新。高光分支预测显著度，检索分支生成候选片段及置信度，并进一步细化时间边界。ASP builds hierarchical representations at different temporal resolutions and selectively updates features across fine- and coarse-grained branches. A highlight head predicts saliency, while the retrieval head generates candidate moments and confidence estimates with temporal-boundary refinement.

实验结果Experiments and Results

实验覆盖 QVHighlights、Charades-STA、TACoS、TVSum 和 Ego4D-NLQ。在 QVHighlights 验证集的全监督 InternVideo2 设置下，BMANet 达到 R1@0.5 73.6、R1@0.7 59.1 和平均 mAP 54.3；相同主干的 FlashVTG 平均 mAP 为 52.8。Evaluation spans QVHighlights, Charades-STA, TACoS, TVSum, and Ego4D-NLQ. With full supervision and InternVideo2 on QVHighlights validation, BMANet reaches 73.6 R1@0.5, 59.1 R1@0.7, and 54.3 average mAP; FlashVTG with the same backbone obtains 52.8 average mAP.

在 Charades-STA 测试集上，R1@0.5 为 70.4、R1@0.7 为 49.0；在 TACoS 测试集上，分别为 40.8 和 26.0。定性示例展示了背景响应抑制、边界定位和非连续事件分离的效果。On the Charades-STA test set, R1@0.5 and R1@0.7 are 70.4 and 49.0; on TACoS they are 40.8 and 26.0. Qualitative examples illustrate background suppression, boundary localization, and separation of discontinuous moments.
