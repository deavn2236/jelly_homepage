# 郭文栋个人学术主页

当前目录就是 GitHub Pages 的发布根目录。`index.html`、`assets/`、`papers/`、`projects/` 可以直接托管；配置和构建脚本一并保存在此仓库，后续修改不用再切换到旧目录。

目标网站：https://deavn2236.github.io/deavn.github.io/

## 本地查看与更新

需要 Node.js 18 或更新版本，没有第三方 npm 依赖，无需 `npm install`。

```powershell
cd 'D:\个人资料\简历\academic-site-github-pages'
npm run check
npm run build
npm run dev
```

访问 `http://127.0.0.1:4173/`。预览不自动刷新，修改配置后重新构建并刷新浏览器；按 `Ctrl+C` 停止预览。

`npm run build` 直接更新当前目录的页面、样式和脚本，保留 Git 仓库与素材。不要将源代码文件单独移动到发布目录外。

## 提交到现有仓库

修改完成后，在当前目录执行：

```powershell
git status
git add .
git commit -m "Update academic homepage content and demonstrations"
git push origin main
```

GitHub Pages 使用 `main / (root)` 发布方式。推送到 `main` 后由 GitHub Pages 更新网站，部署进度可在仓库 Actions 页面查看。

所有正文使用 `{ zh: '中文', en: 'English' }`，新会话默认中文，当前标签页的语言选择会延续到详情页。

导师姓名维护于 `content/site.mjs` 的 `advisors` 数组，位于首页邮箱下方；宽屏占一整行，窄屏按完整姓名自然换行。

首页显示博士在读身份，教育经历保持实际研究生阶段起止信息；业余爱好为听歌和打羽毛球。学生工作结合述职报告与本人补充更新，荣誉按研究生和本科阶段分开，从两份奖项汇总表中选取代表性条目并合并年份。各板块使用本地双色SVG图标，不引入外部图标库。

替换图片后，如尺寸变化，可用安装了 Pillow 的 Python 运行 `python scripts/refresh-images.py` 更新尺寸索引。此步骤仅用于更换素材，正常构建无需 Python。

## 媒体与内容

- 图像保留原始比例，提供320/480/640/960像素缩略图与原图；主设备图缩小显示；并列素材等宽，超宽或不适合配对的素材独占一行。点击图片可查看原图。
- 首页使用不超过10秒的短预览，合计约1.88 MiB；上次二次视频压缩已撤销，83个MP4恢复为此前文件，原分辨率、帧率和画质均保留。详情页保留演示时长，视口外不下载视频。
- 视频均为 H.264/yuv420p、无音轨，使用 faststart；可见时静音自动循环播放，默认1.5倍速，离开视口或进入后台暂停。访问者仍可手动暂停。
- 论文详情包含任务说明、主要贡献、方法架构、实验结果。表格直接采用论文或原材料的完整截图，图片可以点击查看大图；已移除重复的网页表格与指标卡片。
- Kangaroo 首页展示室外实机场景，从原片145.7秒开始，已跳过场景说明动画。大厅运输与末端导航、方法说明、母车走廊运输与轮椅交接视频已删除；论文中的 IF-Planner 和设备图缩小展示。
- 三维激光导航保留地图与局部轨迹可视化主视频，首页使用其10秒无声预览；详情页保留完整主视频并置于演示区开头。首页不显示额外的预览说明文字，设备区将传感器小图放在平台右侧。
- “智能系统”位于机器人项目之前，包含电厂安全识别、人员识别定位与轨迹回放、投标文件识别，配置分组为 `systems`，独立生成详情页。机器人项目分为“主要研发”和“参与项目”；柔性物料抓取位于主要研发，三球一体、棋子视觉抓取、轮腿与果蔬干产线位于参与项目。RFID/NFC项目已移除。ReCoNav仅保留在论文区，标题使用英文。
- 三球一体视频按乒乓球、羽毛球和网球拆分；正文直接说明 YOLO 视觉检测、视觉–运动融合预测、轨迹拟合及 PID/NMPC 控制。方法图保留来源，项目结果采用实机演示，不展示文献中的92.2%/68回合作为项目成绩。
- SCTNav 总览位于详情开头，演示区集中展示实机片段，实验区使用论文原表，不重复放对比视频；网页不依赖原站视频服务才能播放。

### 可选：再次压缩素材

正常构建无需执行。上次视频二次压缩已按本人要求撤销，当前工具默认只处理图片，保留全部MP4及其索引。图像参数维护于 `content/media-policy.json`。

```powershell
python scripts/optimize-media.py --backup 'D:\site-media-backup'
npm run check
npm run build
```

论文表格、方法图采用较高图像质量，照片与视频封面单独压缩，生成四档WebP缩略图。工具刷新图像索引并在仓库外保存修改前素材与 `compression-report.json`。重复处理同一批素材时复用同一备份目录，以免多次有损压缩。仅在确定需要重新压缩视频时，才额外提供 `--videos --ffmpeg 'C:\tools\ffmpeg\bin\ffmpeg.exe'`；这会按保留的紧凑策略重新编码视频。图片、封面和视频URL带内容摘要，更新素材后可自动刷新浏览器缓存。

### 媒体排版配置

详情素材由 `scripts/figure-layout.mjs` 按比例排成等宽双列；超宽图/视频及不适合配对的素材单独成行。相邻素材设置相同的 `row` 值可指定一组（最多两项），`rowWidth` 限制整行宽度；`layout: 'full'` 强制单独成行，`displayWidth` 仅限制单独展示时的宽度。并列图片以较高图片的比例确定共同展示框，两张图片都完整显示并占相同宽度，图注对齐。手机宽度下统一改为单列，保留原始比例。图注类型和说明文字均为14px，并配有本地SVG图标。

论文区保留外层黑框白底卡片；缩略图和介绍链接不加边框，等级使用无外链的浅色标签。正文统一黑色，链接使用深红色；中文优先微软雅黑，英文优先 Times New Roman，其他设备使用相应本地字体回退，不下载或公开系统字体文件。中文模式中的英文论文标题也标记为英文以使用正确字体。图标提供机器人眨眼、天线亮度和页首线路等轻量CSS动效；系统设置减少动态效果时停用动画。未引入外部字体或动画库。

项目卡片的详情链接优先接在简介末行；空间不足时自动换行右对齐。简介文字保持精简，桌面双列下尽量统一行数；改变屏宽、切换语言、筛选项目及字体就绪时会重新检查链接位置，不截断简介。时间在标题上方只显示一次，优先使用 `period`，缺少时再显示 `year`。单位也在标题上方展示。个人资料区标题为“个人主页”，不加外框，使用本地SVG小图标和固定标签列宽对齐资料；学生工作职位仅加粗。详情页不生成章节目录，保留各节标题及锚点。

设备区可设置 `layout: 'equipment'`，将一张主设备图与一张传感器图组合展示；三维激光导航组合宽度上限600px，RTK组合上限560px且可用 `equipmentRatio` 调整左右列比例，传感器缩小放右侧，手机仍保留左右关系。普通结果图和视频继续遵循等宽配对规则。

项目的“系统和关键技术”使用 `techniques: [{ name: { zh, en }, description: { zh, en } }]` 配置，分别说明技术名称、输入输出及作用；“任务说明”保留目标和操作要求。棋子项目的 YOLO/MoveIt 与轮腿项目的 PPO 已由本人补充确认。需要局部加粗的双语正文可配置 `emphasis: { zh: '强调文字', en: 'emphasized phrase' }`，只匹配并加粗指定短语，不写入任意HTML。

可见视频在桌面和手机均尝试静音内联自动播放，默认1.5倍速；源文件加载完成、页面重新显示时补充恢复。若浏览器节电策略阻止播放，可点击播放按钮，或在首次触摸后恢复被阻止的视频。
